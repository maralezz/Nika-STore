💡 Склейка по SKU: если в одном файле товар с фото, а в другом — тот же SKU с ценой, при импорте они объединятся в один товар: фото + характеристики + цена.

Поддерживаются: .xlsx, .xls, .csv

ℹ️ Как это работает

  1. Загружаешь сразу несколько файлов (например, остатки + контент)
  2. Парсер читает все листы каждого файла
  3. Строки-маркеры серий (AQM Tivoli, Aqm Trento и т.п.) автоматически отсеиваются — они не попадают в базу
  4. Товары с одинаковым SKU из разных файлов склеиваются:
    • название — самое полное
    • фото / схемы — объединяются
    • цена — берётся самая большая ненулевая
    • бренд / категория — первая не «Прочие»
    • extra — мерджится по ключам
  5. Цены со служебных листов «РРЦ» / «Акция» применяются по SKU
